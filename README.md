Using the app
Open the Books page to browse sample books. From there, you can view a book’s details, edit it, or delete it.

The app creates 100 sample books when it starts. Because it uses an in-memory database, changes are temporary and reset when the app restarts.

Project layout
BookHub/Controllers - handles web requests and book actions
BookHub/Models - defines the book data
BookHub/Data - sets up and fills the in-memory database
BookHub/Views - contains the pages shown in the browser
BookHub.Tests - test project
